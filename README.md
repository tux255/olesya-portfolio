# Сайт-портфолио Олеси Алексєєнко

**Файл для отдачи:** `index.html` — самодостаточный одностраничник (весь CSS и JS внутри), ассеты в `assets/`.
**Вес:** ~1,2 МБ (в основном скриншоты кейсов).

## Как посмотреть локально

```bash
cd /Users/andrew/Projects/olesya-portfolio/site
python3 -m http.server 8811
# затем открыть http://localhost:8811/
```

Файл можно открыть и просто двойным кликом (`file://index.html`) — всё работает, кроме отсутствия сжатия на сервере.

## Что внутри

1. **Hero** — позиционирование + 3 живые цифры (счётчики анимируются при появлении).
2. **З ким працюю** — три ниши: образование, локальный бизнес, личные бренды.
3. **Що я роблю** — 12 услуг рыночными терминами.
4. **Звёздный блок** — Тіна Кароль / Надя Дорофєєва («747») / окупність 500%.
5. **Кейси (10)** — с фильтрами (Усі / Освіта / Локальний бізнес / Особисті бренди), у каждого «було → результат у цифрах», клик по картинке открывает лайтбокс.
6. **Як я працюю** — 6 шагов.
7. **Тарифи** — реальные: Pro Start 550$ (≈24 500 грн), Growth 750$ (≈33 450), Full Scale 950$ (≈42 370).
8. **Відгуки** — 3 заглушки, ждут реальных текстов.
9. **FAQ** — 5 вопросов (сроки, съёмки, таргет, правки, отчётность).
10. **CTA + контакты** — Instagram (два аккаунта), приглашение в дірект и на зум.

## Технические решения

- Палитра взята из самой презентации: бордо `#660826`, кремовый `#faf1ca`, светло-голубой `#d9f0ff` (контраст всех пар ≥ 5,4:1, проверено расчётом).
- Шрифты: Playfair Display (заголовки), Manrope (текст), Caveat (рукописные акценты) — Google Fonts.
- Анимации: появление секций через IntersectionObserver, счётчики цифр, прогресс-бар чтения, hover-микроанимации. При `prefers-reduced-motion` — всё отключено.
- Прогрессивное улучшение: класс `js` ставится до отрисовки, поэтому без JavaScript страница видна целиком (не «пустая»).
- Проверено: горизонтального переполнения нет на 390 / 768 / 1440 px (scrollWidth == clientWidth, 0 элементов за правым краем).
